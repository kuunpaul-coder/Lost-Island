# Lost Island

An island expansion project for Stardew Valley 1.6.15.3 and Android SMAPI.

## Current status

This repository contains the initial Content Patcher pack structure:
- `manifest.json` — pack metadata and Content Patcher dependency.
- `content.json` — patch entry point (currently empty).

**This is a development scaffold, not a playable island yet.** The island map, location registration, transitions, NPCs, quests, and assets still need to be implemented and tested in-game.

## Planned island regions

1. Port — arrival point and boat landing.
2. Abandoned Town — ruined homes, shops, and clues.
3. Jungle — forage, rare resources, and hidden paths.
4. Central Square — the island's main hub.
5. Underground Tunnels — connected exploration routes.
6. Old Mine — deeper resource and treasure area.
7. Lighthouse — landmark and quest destination.

## Compatibility target

- Stardew Valley 1.6.15.3
- SMAPI 4.3.2.5 on Android
- Content Patcher 2.x

The project will prioritize Android-safe assets and avoid requiring a desktop-only installation workflow.
